# Lentes e espelhos

Lentes finas e espelhos esfericos ideais podem ser lidos por uma mesma relacao paraxial de pontos conjugados:

```math
\frac{1}{f}=\frac{1}{d_o}+\frac{1}{d_i}
```

O aumento linear mostra se a imagem fica direita ou invertida:

```math
m=-\frac{d_i}{d_o}=\frac{h_i}{h_o}
```

Nesta cena, focos positivos representam lentes convergentes e espelhos concavos. Focos negativos representam lentes divergentes e espelhos convexos. Quando `d_i` fica negativo, a imagem e virtual: os prolongamentos indicam de onde os raios parecem vir.

## Como interpretar

- Aproximar o objeto do foco torna a distancia de imagem muito sensivel.
- Em uma lente convergente com `d_o = 2f`, a imagem aparece perto de `2f` do outro lado e com aumento `m = -1`.
- Objeto dentro do foco de elemento convergente gera imagem virtual ampliada.
- Elementos divergentes ou convexos tendem a produzir imagem virtual reduzida.
- A abertura dos raios muda o desenho do banco optico, mas nao troca a equacao usada para `d_i`.

## Limites declarados no fixture

- Regime paraxial: raios proximos ao eixo principal.
- Sem aberracoes, espessura real de lente, dispersao cromatica ou tamanho finito de espelho.
- Quando a imagem vai para muito longe, o sample limita a distancia desenhada para manter a cena legivel.
